# Fragments of Me

A cinematic personal journal website for GitHub Pages.

## How to replace the images

Open the `images` folder and replace the placeholder SVG files with your own photos.

Recommended filenames:
- cover.jpg
- intro.jpg
- photo01.jpg
- photo02.jpg
- photo03.jpg
- quote.jpg
- fragment.jpg
- closing.jpg

Then change the matching `--bg:url('../images/....')` in `index.html`.

You can also keep the SVG placeholders until you are ready.
